# Feature Flow & User Stories

## User Flow

1. User opens dashboard
2. User creates a project
3. User pastes requirement text
4. User selects generation type
5. AI generates artifacts
6. Output displayed in editor
7. User copies or downloads output
8. Generation saved to history

---

## User Stories

### Story 1

As a QA engineer
I want to paste a requirement
So that AI can generate test cases.

---

### Story 2

As an automation engineer
I want AI to generate Gherkin scenarios
So that I can use them in Cucumber automation.

---

### Story 3

As a developer
I want step definition skeletons
So that I can quickly start Selenium automation.

---

### Story 4

As a user
I want to save generation history
So that I can revisit previous outputs.

---

### Story 5

As a user
I want to download generated artifacts
So that I can share them with my team.
